# Requerimientos No Funcionales
| ID       | Categoría  | Descripción                                                                         |
| -------- | ---------- | ----------------------------------------------------------------------------------- |
| RnF_U001 | Usabilidad | La interfaz debe ser intuitiva y accesible para usuarios sin conocimientos técnicos |
| RnF_U002 | Usabilidad | El diseño debe ser responsivo (adaptarse a móviles y tablets).                      |
| RnF_U003 | Usabilidad | Debe incluir mensajes claros de validación y error                                  |

| ID       | Categoría   | Descripción                                                                                  |
| -------- | ----------- | -------------------------------------------------------------------------------------------- |
| RnF_P001 | Rendimiento | El sitio debe cargar en menos de 3 segundos en conexiones estándar                           |
| RnF_P002 | Rendimiento | El configurador debe responder dinámicamente sin recargar la página (uso de JavaScript/AJAX) |

| ID       | Categoría      | Descripción                                                                                                                       |
| -------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| RnF_S001 | Seguridad      | Los formularios deben validar entradas para evitar inyecciones SQL o XSS                                                          |
| RnF_S002 | Seguridad      | La información del usuario debe manejarse de forma segura (uso de HTTPS)                                                          |
| RnF_S003 | Seguridad      | El sistema debe proteger los datos personales conforme a la legislación mexicana (Ley Federal de Protección de Datos Personales)  |

| ID       | Categoría      | Descripción                                                                                                                       |
| -------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| RnF_M001 | Mantenibilidad | El código debe estar modularizado y documentado para facilitar futuras actualizaciones                                            |
| RnF_M002 | Mantenibilidad | El sistema debe permitir agregar nuevas categorías de configuración sin rediseñar toda la lógica |

| ID       | Categoría      | Descripción                                                                                                                       |
| -------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| RnF_E001 | Escalabilidad  | El sistema debe poder crecer para incluir más tipos de equipos, configuraciones o servicios (como accesorios, periféricos, etc.). |

| ID       | Categoría      | Descripción                                                                         |
| -------- | -------------- | ----------------------------------------------------------------------------------- |
| RnF_C001 | Compatibilidad | Debe funcionar correctamente en los principales navegadores (Chrome, Firefox, Edge) |
| RnF_C002 | Compatibilidad | Debe ser compatible con versiones recientes de HTML5 y CSS3                         |
